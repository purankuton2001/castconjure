# Code of Conduct

Be kind, be specific, be constructive. This project touches fandom, likeness and generated media, so two extra rules apply to every discussion, issue and PR:

1. **No requests for real people or existing characters.** Asking how to make the persona look or sound like a real idol, actor, VTuber or an existing anime/game character will be closed without discussion.
2. **No harassment of anyone, real or generated.** Content that sexualises, demeans or targets a person — or that treats the generated persona as a way to do so — is out of scope here.

Report problems to the maintainer via a GitHub issue or the email on the profile. Maintainers may edit, lock or remove content and ban repeat offenders. This document is short by design; when in doubt, ask.
